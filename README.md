# Nosso Cantinho

## Versão 4.17 — aviso claro sobre cotas
Atualize pelo próprio app nos dois celulares, instalando por cima sem desinstalar.

O aviso HTTP 429 agora explica que o servidor público ntfy.sh recusou temporariamente o envio por cota ou volume de pedidos. Essa cota pode ser compartilhada por vários celulares que saem pela mesma internet/IP. HTTP 413 identifica o limite de tamanho de anexo. A tela Sobre explica que o serviço externo tem cotas e que o app não pode torná-las ilimitadas.

Esta versão melhora o diagnóstico; as cotas do ntfy.sh continuam valendo. Para mensagens, arquivos e armazenamento sem cotas impostas por esse serviço será necessário migrar para um backend próprio ou serviço com plano adequado. Teste de mensagens de erro, compilação, assinatura e integridade do APK conferidos. Não houve teste em aparelho nesta sessão.
