# Nosso Cantinho

## Versão 4.18 — correção do atualizador
Atualize pelo próprio app nos dois celulares, instalando por cima sem desinstalar.

A verificação de APK agora usa a API atual de assinatura do Android e compara a versão longa do pacote. O aviso aponta a causa específica quando versão ou assinatura não conferem. O número usado pelo bloqueio de atualização obrigatória foi sincronizado com esta versão.

Compilação Android 35, assinatura original e manifesto conferidos. Não houve teste em aparelho nesta sessão; confirmem a atualização nos dois celulares.

## Publicação
APK e update.json são publicados juntos, com SHA-256. Não publicar chave privada, ZIP do projeto, código do casal, dados pessoais, coordenadas, mídias ou backups.
